## Approach notes
- **Item 5** — `role="img"` goes on a div wrapping only the `ResponsiveContainer`, never the whole card body, so the allocation donut's text legend stays readable to screen readers.
- **Item 7** — value-line `'auto'` drops the zero baseline (a deliberate call: a personal portfolio chart is read for *change*, not absolute floor); the P&L *area* keeps a zero floor since an area reads as magnitude.
- **Item 6** — `ImportWizard` is already self-contained (`useReducer`, no router loader), so the extraction is a clean route addition.
- **Item 11** — totals sum the `rows` prop (already filtered), not all holdings, so the footer reflects what's visible.

## Reliability tenets

- **T3 (blast radius)**: each fix is scoped to its component; no shared-primitive changes.
