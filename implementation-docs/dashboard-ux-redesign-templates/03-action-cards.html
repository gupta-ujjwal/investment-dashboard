THE COMPONENT THE APP IS MISSING · Every card is the same three parts — signal → number → one primary action. Never more than one primary button; a second action is always ghost. A card exists only while its rule fires; there is no dismiss in v1, because a dismissable card is a card the user never fixes. The rail resolving to zero is the retention loop.

// src/lib/actionRail.ts — pure, no storage reads, fully unit-testable

export type ActionItem = {
  id: string              // stable key — 'risk-drift-high', 'emergency-gap'
  severity: ActionSeverity

  emphasis: string        // the substring rendered in the severity colour
  detail: string          // one supporting line, never a second sentence of advice
  primary: { label: string; to: string }
  secondary?: { label: string; to: string }
}
